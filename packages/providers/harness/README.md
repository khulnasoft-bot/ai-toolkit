# AI TOOLKIT - Harness Base

Shared harness contracts (`@ai-toolkit/harness`) for `HarnessAgent` harnesses: `HarnessPermissionMode`, the `Harness` identity interface, and `HarnessCapabilityUnsupportedError`.

> Experimental: expect breaking changes between releases.

Per-runtime adapters live in `@ai-toolkit/harness-acp` (generic ACP-v1) and `@ai-toolkit/harness-<agent>` (one profile per agent).
