## Prerequisites

Before you begin, install:

- Node.js 20.9 or later
- pnpm
- Git

The AiDocs CLI always uses pnpm to install the generated project's dependencies. Running the CLI through `npx` does not remove the pnpm requirement.

## Choose a release channel

Use `@ai-toolkit/ai-docs@latest` for the current stable package-backed release. Use `@ai-toolkit/ai-docs@canary` only when you need changes being evaluated on the `canary` branch, including the current Geistcn migration.

The canary dist-tag can move several times in one day. The CLI resolves the tag once and writes that exact version to the generated `package.json`.

## Authenticate for the Geistcn canary

The Geistcn canary depends on restricted `@vercel/geistcn` and `@vercel/geistcn-assets` packages. Configure npm authentication before running the canary CLI. Add this configuration to your user-level `~/.npmrc`:

```ini title="~/.npmrc"
@vercel:registry=https://registry.npmjs.org/
//registry.npmjs.org/:_authToken=${NPM_TOKEN}
always-auth=true
```

Set `NPM_TOKEN` from an approved internal source and keep its value out of files and Git. Stable AiDocs does not currently require these restricted packages. Read [Deploy to Vercel](/docs/deployment) before configuring automated installs.

## Create a project

Run the AiDocs CLI from an empty parent folder. For stable AiDocs, run:

```bash title="Terminal"
pnpm dlx @ai-toolkit/ai-docs@latest init --name my-docs
```

For the Geistcn canary, run:

```bash title="Terminal"
pnpm dlx @ai-toolkit/ai-docs@canary init --name my-docs
```

The CLI copies the template bundled in the package, rewrites the generated app to depend on the same `@ai-toolkit/ai-docs` version, installs dependencies, copies `.env.example` to `.env.local`, and initializes Git.

## Understand generated dependencies

Generated projects include `@ai-toolkit/ai-docs`, `ai` v6, and `@ai-sdk/react` v3. AiDocs uses those AI SDK packages for Ask AI, including the chat client transport and `createChatRoute` server behavior. Canary projects also declare the matching `@vercel/geistcn` and `@vercel/geistcn-assets` versions directly because generated application files import them.

Update Ask AI by updating `@ai-toolkit/ai-docs`, not by copying package chat internals into the app. If your project uses the AI SDK directly for separate product features, keep that code compatible with the app's installed AI SDK version; package-owned Ask AI does not need to match another consumer project's `ai` version.

## Start the development server

Open the generated project and start Next.js:

```bash title="Terminal"
cd my-docs
pnpm dev
```

Open `http://localhost:3000` in your browser.

## Edit your first page

Docs live in `content/docs`. Edit the overview page:

```mdx title="content/docs/index.mdx"
---
title: Overview
description: Learn how to use my project.
---

My project helps developers build with clear documentation.

## Start here

Add the first workflow you want readers to complete.
```

Add more pages by creating new `.mdx` files in `content/docs`.

## Update the sidebar

Use `content/docs/meta.json` to control page order and groups:

```json title="content/docs/meta.json"
{
  "title": "Documentation",
  "root": true,
  "pages": ["index", "getting-started", "---Guides---", "deploy"]
}
```

Page and folder entries use names without extensions. A value such as `---Guides---` creates a non-clickable separator label. Read [Configure sidebar navigation](/docs/guides/nested-navigation) to add folder landing pages, deeply nested folders, custom links, and `defaultOpen` behavior.

## Configure the site

Use `ai-docs.tsx` to customize the site shell:

```tsx title="ai-docs.tsx"
export const title = "My Documentation";

export const nav = [
  { label: "Docs", href: "/docs" },
  { label: "GitHub", href: "https://github.com/my-org/my-repo" },
];
```

Read [Configuration](/docs/configuration) for the full configuration surface.

## Update AiDocs

For package-based projects, `ai-docs update` updates the `@ai-toolkit/ai-docs` package version. It does not overwrite your local content or adapter files. Projects already using a canary version continue to follow the `canary` dist-tag; stable projects follow `latest`.

```bash title="Terminal"
pnpm exec ai-docs update
```

Review and test dependency changes before committing.
