# Adapter Layer

Framework-specific implementations that wrap the core SDK with idiomatic APIs for each framework.

**Owner**: @khulnasoft/ai-toolkit-adapters

| Adapter   | Framework   | Exports                           |
| --------- | ----------- | --------------------------------- |
| `react`   | React 18+   | useChat, useCompletion, useObject |
| `rsc`     | Next.js 13+ | Server actions, RSC helpers       |
| `angular` | Angular 15+ | Directives, services              |
| `svelte`  | Svelte 3+   | Stores, components                |
| `vue`     | Vue 3+      | Composables                       |
